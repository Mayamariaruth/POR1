Live Site GitHub README

Shopella is a modern e-commerce web application built with React and TypeScript, focusing on clean architecture, state management, and user experience. The application allows users to browse a dynamic product catalog, explore individual product details, add items to a shopping cart, and complete a mock checkout process.

The project demonstrates routing, persistent global state, form validation, and responsive design principles. Special attention was given to creating a smooth shopping flow, clear feedback interactions, and structured component organization using modern React best practices.

Key Features

  • Product Browsing: View a full product catalog with individual product detail pages.
  • Shopping Cart: Add items, adjust quantities, remove products, and persist cart data using Zustand.
  • Routing: Navigate between pages seamlessly using React Router.
  • Form Validation: Contact form validation implemented using Yup.
  • User Feedback: Toast notifications powered by React Toastify.
  • Responsive Design: Built with Bootstrap and custom CSS for a clean and mobile-friendly interface.
