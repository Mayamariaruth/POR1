Chattr

Profile page of a social posting interface demonstrating responsive layout and custom Bootstrap styling.

Live Site GitHub README

Chattr is a responsive social posting application interface built using Bootstrap with custom SCSS overrides. The project focuses on front-end structure, layout composition, accessibility, and visual consistency. It simulates a modern social media platform where users can create and view posts in a clean and intuitive UI.

Although the application is fully static and does not include backend functionality, it demonstrates strong understanding of component structure, responsive grid systems, semantic HTML, and customized design systems. The goal was to create a polished, accessible, and visually cohesive interface while working within a structured CSS framework.

Key Features

  • Responsive New Post Form: Client-side validation with accessible labels and structured input fields.
  • Custom Bootstrap Theme: Modified Bootstrap using SCSS variables to create a consistent brand style.
  • Accessible Design: Clear labels, placeholders, semantic HTML structure, and ARIA attributes.
  • Structured Layout: Organized HTML/CSS optimized for clarity, maintainability, and scalability.
  • Interactive UI States: Hover effects and visual feedback for improved user experience.
